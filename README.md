# 더원 PDS 플래너

습관코치 더원(네오)의 하루를 **Plan(계획) → Do(실행) → See(리뷰)** 로 관리하는 웹앱.
루틴 문서(3대 관리 영역 · 평일/주말 루틴 · 원시인 버튼 스캔)를 기본값으로 담았습니다.

## 기능
- **Plan**: 어제 리뷰의 '내일 바꿀 1가지' 표시 → 오늘의 의도 · 핵심 3 · 이번 주 3대 영역 목표 · 시간 블록(요일별 루틴 템플릿 자동 생성) · 할 일 · 독서 4트랙 책/실행 과제
- **Do**: '지금' 카드(현재 블록, 남은 시간, 집중 타이머) · 타임라인 ✓/△/✕ · 핵심 3 · 오늘 런닝(런닝 캘린더 연동) · 원시인 버튼(평일 8 / 주말 15, Y가 아니면 N) · SNS 카운터 · 독서 쪽수
- **See**: 자동 PDS 점수 + Keep/Problem/Try 하루 리뷰 → 내일 Plan 연결 · 주간 리뷰(7일 차트, 다음 주 목표) · 월간 히트맵
- 설정: 루틴 템플릿, 원시인 항목, SNS 목표, 독서 트랙, 목표 대회, 백업(JSON)
- PWA: 홈 화면 추가, 오프라인 셸

## 구조
빌드 없는 정적 사이트. `config.js`에 Supabase URL/publishable 키가 있으면 클라우드, 비우면 localStorage 모드.
Supabase 테이블은 `schema.sql` (pds_profile / pds_days / pds_weeks, jsonb + 본인 전용 RLS).
런닝 캘린더와 같은 Supabase 프로젝트를 써서 같은 계정으로 로그인하고 `workouts`, `races`를 읽기 전용으로 보여줍니다.

PDS 점수 = 블록 실행률 · 원시인 버튼 · 핵심 3 · SNS 달성률의 평균(값이 있는 항목만).
