# 더원 PDS 플래너

습관코치 더원(네오)의 하루를 **Plan(계획) → Do(실행) → See(리뷰)** 로 관리하는 웹앱.
루틴 문서(3대 관리 영역 · 평일/주말 루틴 · 원시인 버튼 스캔)를 기본값으로 담았습니다.

## 기능
- **홈 대시보드 (첫 화면)**: 오늘 요약(PDS 점수·블록·원시인·핵심 3·리뷰) · 월간 캘린더(점수 색, 런닝/리뷰 표시) · 분야별 현황(런닝 / 독서 / SNS / 온라인사업) · P·D·S로 나눈 할 일 보드(자동 체크 항목 + 직접 추가)
- **Plan**: 어제 리뷰의 '내일 바꿀 1가지' 표시 → 오늘의 의도 · 핵심 3 · 이번 주 3대 영역 목표 · 시간 블록(요일별 루틴 템플릿 자동 생성) · 할 일 · 독서 4트랙 책/실행 과제
- **Do**: '지금' 카드(현재 블록, 남은 시간, 집중 타이머) · 타임라인 ✓/△/✕ · 핵심 3 · 오늘 런닝(런닝 캘린더 연동) · 원시인 버튼(평일 8 / 주말 15, Y가 아니면 N) · SNS 카운터 · 독서 쪽수
- **See**: 자동 PDS 점수 + Keep/Problem/Try 하루 리뷰 → 내일 Plan 연결 · 주간 리뷰(7일 차트, 다음 주 목표) · 월간 히트맵
- 설정: 루틴 템플릿, 원시인 항목, SNS 목표, 독서 트랙, 목표 대회, 근무표, 백업(JSON)
- PWA: 홈 화면 추가, 오프라인 셸

## 일정 (2026-10-29 추가)
- 홈(다가오는 일정 카드, 달력 아래 '+ 일정'), Plan 탭 '📌 일정' 카드, Do 타임라인 아래의 **+ 일정 추가** 버튼 → 폼(날짜 · 시작/끝 시간(비우면 종일) · 제목 · 영역 · 메모 · 알림).
- 알림: 없음 / 정각 / 10분 전 / 30분 전 / 1시간 전 / 하루 전 / 전날 21시. 종일 일정은 '종일 기준 시각'(기본 09:00) 기준.
- 표시: 홈 달력에 일정 수 배지(빨강, 모두 완료면 회색) · 날짜를 누르면 달력 아래에 그날 일정 · 홈 상단 '다가오는 일정'(오늘~7일) · Do 타임라인에 시간순(점선 + '일정' 태그) · 홈 P·D·S 보드 D열.
- 체크박스로 완료, 일정을 누르면 수정·삭제(두 번 눌러 확인).
- 저장: `pds_events` 테이블(블록과 별도) → 근무표 변경이나 '템플릿으로 다시 만들기'로 지워지지 않음. JSON 백업에도 포함.

## 알림 (2026-10-29 추가)
- 설정 탭 **🔔 알림**: 이 기기에서 알림 켜기(권한 요청 + 웹푸시 등록) · 테스트 알림 · 이 기기 알림 끄기 · 새 일정 기본 알림 · 블록 시작 알림(정각/5/10/15분 전, 영역별 선택) · 아침 Plan 알림 시각 · 하루 리뷰 알림 시각 · 집중 타이머 종료 알림.
- 앱을 닫아도 오는 웹푸시: 기기 구독은 `pds_push_subs`, 루틴 알림(블록·Plan·리뷰·타이머)은 앱이 14일치를 `pds_push_queue`에 예약(설정·블록을 바꾸거나 앱을 열 때 갱신), 일정 알림은 `pds_events.remind_at`.
- 발송: Edge Function `pds-push`(`edge-function-pds-push.ts`)를 pg_cron이 1분마다 호출. 보낼 행을 먼저 `sent_at`/`reminded_at`으로 선점해 중복 발송 방지, 15분 넘게 지난 알림은 보내지 않음, 리뷰를 이미 쓴 날은 리뷰 알림 건너뜀. VAPID 키·CRON_SECRET은 런닝 캘린더와 같은 프로젝트 시크릿 재사용.
- 앱이 열려 있을 때는 15초마다 앱 안에서도 확인해 토스트 + 서비스워커 알림을 띄움(같은 tag라 푸시와 겹쳐도 하나만 남음).
- 아이폰·아이패드는 Safari 공유 → **홈 화면에 추가**한 앱에서만 푸시 가능(iOS 16.4+). 기기마다 한 번씩 '이 기기에서 알림 켜기'.
- 알림을 누르면 해당 탭·날짜로 열림(`?tab=do&date=YYYY-MM-DD`).

## 구조
빌드 없는 정적 사이트. `config.js`에 Supabase URL/publishable 키가 있으면 클라우드, 비우면 localStorage 모드.
Supabase 테이블은 `schema.sql` (pds_profile / pds_days / pds_weeks, jsonb + 본인 전용 RLS / pds_events / pds_push_subs / pds_push_queue).
런닝 캘린더와 같은 Supabase 프로젝트를 써서 같은 계정으로 로그인하고 `workouts`, `races`를 읽기 전용으로 보여줍니다.

PDS 점수 = 블록 실행률 · 원시인 버튼 · 핵심 3 · SNS 달성률의 평균(값이 있는 항목만).
